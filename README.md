# Aditya Verma — Portfolio

A minimal, Editorial Brutalist portfolio built with React and Vite.

## Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:5173](http://localhost:5173) in your browser.

## Editing Content

All site content (skills, projects, links, etc.) lives in `src/data/content.js`. 
You can edit this file to update the site without touching any component code.

## Building for Production

To create a production build:
```bash
npm run build
```
This will generate a `dist` folder.

## Deployment (Vercel)

This project is ready to be deployed on Vercel as-is.
1. Push your code to GitHub.
2. Import the repository in Vercel.
3. Vercel will automatically detect Vite and configure the build settings.
4. Deploy!
